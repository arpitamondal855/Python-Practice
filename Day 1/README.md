## Programming Exercises

### Problem 01: Number Swapping

Develop a Python program that accepts two numbers from the user and exchanges their values.

**Sample Input:**

* First Number: 15
* Second Number: 30

**Expected Output:**

* First Number: 30
* Second Number: 15

### Problem 02: Temperature Converter

Create a Python program that reads a Celsius temperature, converts the input into a floating-point number, and displays the corresponding Fahrenheit temperature.

**Conversion Formula:**

`F = (C * 9/5) + 32`

**Sample Input:**

* Celsius: 30

**Expected Output:**

* Fahrenheit: 86.0°F

### Problem 03: Circle Area Calculator

Build a Python program that receives the radius of a circle and determines its area using the mathematical formula.

**Formula:**

`Area = 3.14 * radius ** 2`

**Sample Input:**

* Radius: 10

**Expected Output:**

* Circle Area: 314.0

### Problem 04: Simple Interest Calculation

Implement a Python program that collects the principal amount, annual interest rate, and time period from the user. Convert the provided values into floating-point numbers and calculate the simple interest.

**Formula:**

`Simple Interest = (Principal * Rate * Time) / 100`

**Sample Input:**

* Principal: 5000
* Rate: 6%
* Time: 3 Years

**Expected Output:**

* Simple Interest: 900.0
